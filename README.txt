ПОРТФОЛИО · 3 УЧЕБНЫХ ПРОЕКТА · 2026

Откройте index.html в любом современном браузере.

1. coffee/index.html — адаптивный лендинг кофейни VERDE.
   Особенности: фильтры меню, адаптивное навигационное меню, уведомления.
2. cleaning/index.html — адаптивный лендинг клинингового сервиса CLEANO.
   Особенности: калькулятор цены, форма с браузерной валидацией, FAQ, модальное окно.
3. bugfix/index.html — интерактивная имитация исправления мобильной вёрстки.
   Особенности: переключение состояний «до/после», демонстрация overflow и responsive-layout.

Важно: бренды и данные вымышленные. Это демонстрационные примеры, а не выполненные заказы.
Формы и уведомления не связаны с backend, реальные заявки не отправляются.

Для публикации: загрузите каталог на GitHub Pages, Netlify или любой статический хостинг.
Запускать npm и устанавливать зависимости не требуется.

Файлы preview_*.png в папке previews — скриншоты страниц для портфолио бирж.
